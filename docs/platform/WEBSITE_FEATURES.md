# Userside Website Features - Detailed Flow

The userside website is the public face of Madni Education. It helps visitors understand the trust, schools, updates, donation needs, alumni impact, CSR opportunities, and public registration flows.

## Feature 35: Public Home Page

The home page introduces Madni Education and gives visitors a quick understanding of the mission, schools, impact, latest updates, and available actions.

It should guide different audiences: donors, alumni, parents, students, CSR contacts, and school stakeholders.

## Feature 36: Trust and School Discovery

The website can show trusts and schools so visitors can understand the organization structure. School discovery helps users find school-specific details instead of seeing only generic content.

This is useful when multiple schools are managed under the same trust.

## Feature 37: School Detail Pages

School detail pages show public information about a specific school. This can include school profile, student strength, facilities, programs, teachers, events, donation information, and gallery.

These pages help donors and alumni connect with a specific school instead of the platform feeling abstract.

## Feature 38: Latest Updates and News

The website shows latest updates from Madni Islamic Study Centre and other school/admin updates. Each card should show proper text and uploaded images where available.

This keeps the website alive and helps visitors see recent work, achievements, and announcements.

## Feature 39: Events and Gallery

Public events and gallery sections show school activities with images. This helps prove real activity and gives visitors confidence in the platform.

Event media should use uploaded images from school/admin modules and fallback images only when no real image exists.

## Feature 40: Donation Needs and Financial Transparency

The website can show donation needs, active projects, sponsorship categories, completed projects, and financial transparency information.

This helps donors understand what is needed, what has already been completed, and where their contribution can help.

## Feature 41: Public Donation Inquiry and Payment Flow

Public users can submit donation inquiries and continue through payment/verification flows where enabled. Payment receipts/downloads can support donor trust.

This flow should be secure, rate-limited, and clearly connected to the selected school, project, category, or student need.

## Feature 42: Public Alumni Registration

Old students can start alumni registration from the public/alumni registration flow. They submit school and personal details and then wait for school approval.

This keeps the alumni network growing while still letting the school verify identity before account access is created.

## Feature 43: Public Alumni Content

The website can show alumni profiles, alumni of the year, featured stories, achievements, mentorships, blogs, and career-related public content.

This improves community trust and shows the long-term impact of the education work.

## Feature 44: CSR Inquiry and Opportunity Registration

CSR contacts or alumni can submit CSR inquiries and opportunity registrations. This creates a path for organizations, companies, and donors to support schools in a structured way.

CSR data should be visible to the right admin team so it can be followed up properly.
